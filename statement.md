\# Project Statement



\## Problem Statement



The project aims to develop an interactive number guessing game using

Python. In the game, the computer generates a secret number and the

user has a limited number of attempts to guess it. The game provides

hints such as whether the guess is too high, too low, or very close to

the secret number.



\## Scope of the Project



The project includes three difficulty levels, input validation, limited

attempts, hints, best-score tracking and score storage using a text file.

The game can be played through both a terminal interface and a

graphical user interface.



\## Target Users



The project is intended for students and casual users who want to play

a simple interactive number guessing game.



\## High-Level Features



\- Three difficulty levels: Easy, Medium and Hard

\- Random number generation

\- User input validation

\- Too high and too low hints

\- Very close hint

\- Limited number of attempts

\- Best-score tracking

\- Saving and loading scores using a text file

\- Terminal version of the game

\- Graphical user interface using Tkinter
